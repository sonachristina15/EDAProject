# Credit Score Analysis and Classification for Paisabazaar

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a credit score dataset associated with Paisabazaar. The objective is to understand customer credit profiles, identify patterns in the data, and explore factors associated with credit scores.

The project includes data cleaning, preprocessing, univariate, bivariate, and multivariate analysis, data visualizations, and business insights.

## Objectives

- Clean and preprocess the dataset for analysis.
- Explore data distributions and relationships between variables.
- Identify patterns and factors associated with customer credit scores.
- Communicate findings through visualizations and business insights.

## Project Files

- `Copy_of_Sample_EDA_Submission_Template.ipynb` — Google Colab notebook containing the project analysis.
- **Dataset** — Downloaded automatically from Google Drive when the notebook is executed.

## Tools and Technologies

- Python

## Dataset Access

The dataset is hosted on Google Drive because its file size exceeds GitHub's standard browser upload limit. The notebook uses `gdown` to download the dataset automatically before loading it into Pandas.

Ensure the Google Drive file is accessible before running the notebook.
